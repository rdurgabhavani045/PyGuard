# PyGuard – Python Static Code Analyzer

## Project Description
PyGuard is a web-based Python Static Code Analyzer that analyzes
Python source code without executing it.

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

## Features
- Python code editor
- Python file upload
- Syntax checking
- Security checking
- Code quality checking
- Code style checking
- Quality score
- Analysis history
- User login and registration

## How to Run
1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy PyGuard into:
   C:\xampp\htdocs\PyGuard
4. Create the `pyguard` database in phpMyAdmin.
5. Import/create the required tables.
6. Open:
   http://localhost/PyGuard/
